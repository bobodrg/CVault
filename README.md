# CVault

A job radar that checks new postings every morning and ranks them against your CV, with the matching done **entirely on your phone**. Your CV never leaves the device.

Project for the Mobile Computing course (MSc Parallel and Distributed Computer Systems, UPB, 2026–2027).

## Stack

Kotlin · Jetpack Compose + Material 3 · MVVM · Hilt · Navigation Compose · Room · Retrofit · WorkManager · Coil · MediaPipe (on-device text embeddings). Min SDK 26.
